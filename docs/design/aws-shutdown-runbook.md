# AWS 결제 완전 중단 런북 (종료 절차)

- 작성: 2026-11-07, Claude 정리(사용자 요청)
- 출처: **AWS 콘솔 AI 어시스턴트 답변**(사용자가 받은 내용) + Claude 보충. 공식 문서로 재확인하지 않은 항목은 ⚠️로 표시
- 배경: 결정 7로 Paid plan(종량제) + 고급 기능(Organizations)을 켰다. 지출 한도(자동 차단)는 고급 기능 활성화로 **삭제**됐다 → 끄지 않으면 매달 청구된다

## 핵심

**프로젝트(계정)를 닫아도 즉시 $0이 되지 않는다.**

```
프로젝트 닫기 (예: 11월 7일)
   ↓  닫기 전까지 쓴 요금 → 다음 달 초 청구
90일 post-closure 기간 (데이터 보존 — 남은 자원이 있으면 계속 과금될 수 있음)
   ↓
90일 후 영구 삭제 → 이후 청구 없음
```

## 완전한 $0을 위한 순서 (어시스턴트 안내)

1. **자원을 먼저 전부 삭제** — EC2, EBS 볼륨·스냅샷, 탄력적 IP(Elastic IP), S3 버킷(객체 포함), RDS 등
2. **CloudTrail 트레일 삭제** — 명시적으로 지우지 않으면 닫은 뒤에도 과금될 수 있음
3. **Business Support+ 취소** — 유료 지원 플랜이 켜져 있다면
4. **프로젝트 닫기**

→ 닫은 시점 이후 추가 청구 없음, 닫기 전 사용분만 다음 달 초 마지막 청구.

## 확인 방법

- ⚠️ **모든 리전**을 본다 — 다른 리전에 실수로 만든 자원이 가장 흔한 누락. Resource Explorer 또는 Tag Editor(리전 "All")로 조회
- Billing → **청구서(Bills)**: 다음 달 초 마지막 청구 이후 0인지
- Cost Explorer: 서비스별 일 단위 비용이 0으로 떨어졌는지

## 완전 탈퇴 (회원 탈퇴) — 4단계 (어시스턴트 안내, 2026-11-07)

위 "완전한 $0" 절차가 ①·②이고, 그 뒤에 관리 계정과 Builder ID를 정리한다.

```
① 자원 전체 삭제(비용 차단) → ② 프로젝트 닫기 → ③ 관리 계정 닫기 → ④ AWS Builder ID 삭제(선택)
```

| 단계 | 방법 | 조건·메모 |
|---|---|---|
| ① 자원 전체 삭제 | 위 표 전부 + CloudTrail | 건너뛰면 프로젝트를 닫은 뒤에도 잔여 요금 가능 |
| ② 프로젝트 닫기 | AWS Settings → 프로젝트 선택 → **Close project** | 90일 post-closure(데이터 보존) |
| ③ 관리 계정 닫기 | AWS Settings → Project → Actions → **Close management account** | **모든 프로젝트를 닫은 뒤에만** 가능. 90일 post-closure |
| ④ Builder ID 삭제(선택) | `profile.aws.amazon.com` → Privacy & data → **Delete AWS Builder ID** | 관리 계정을 닫은 뒤. Builder ID는 무료라 안 지워도 비용 없음 |

주의사항:

| 항목 | 내용 |
|---|---|
| 마지막 청구 | 닫기 전 사용분은 다음 달 초 1회 청구 |
| 같은 이메일 재사용 | **탈퇴 후 같은 이메일로 새 계정을 만들 수 없음** → 루트 이메일 `+aws` 별칭이 여기서도 유리(다른 별칭으로 새로 만들 수 있음) |
| 소셜 로그인 | Builder ID를 지워도 Google/Apple 계정 자체는 그대로 |
| 90일 이내 재개 | 마음이 바뀌면 90일 안에 Support에 연락해 재개 가능 |

> ⚠️ 어시스턴트는 탈퇴 전 "Spend Limit 설정"으로 비용을 $0으로 만드는 방법도 권했지만, 이 계정은 **고급 기능 활성화로 지출 한도가 삭제됐다**(활성화 1단계 화면 문구). 우리 계정에는 해당하지 않는다 → 비용 감지는 Budgets 알림으로 한다.
